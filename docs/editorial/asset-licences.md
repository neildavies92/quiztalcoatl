# V-001 asset provenance and licence register

Research access: 2026-10-26. Human rights/use-context review: **pending**.

All files are downloaded PNG derivatives generated by Wikimedia from the listed SVG artwork,
not AI artwork and not locally redrawn or converted. The particular source-file pages report
`LicenseShortName: Public domain` and `Copyrighted: False`; the dataset records `public-domain`
as that source's copyright designation. This does not claim a national symbol has no restrictions.
All source pages carry insignia notices (Poland also has `Polishsymbol`).

The machine-readable [asset provenance register](asset-provenance.json) stores each exact source
page revision, native file title, original upload URL/timestamp/SHA1, original dimensions,
creator/credit as supplied by the source, copyright notices, derivative URL, PNG dimensions and
SHA-256. Source author fields such as “Unknown” or “See below” are quoted metadata, not invented
identities; consult the source page where credits are incomplete. Public-domain works do not
receive fabricated Creative Commons licence labels or attribution obligations. The source artist
is nevertheless retained in `AssetReference.attribution` for transparency.

## Acquisition and reproducibility

The Commons API request used `action=query`, `prop=imageinfo`,
`iiprop=url|extmetadata|size|sha1|timestamp`, `iiurlwidth=1920` and each exact `File:Flag of …svg`
title. A second `prop=revisions`, `rvprop=ids|content`, `rvslots=main` query recorded the
source description revision and its actual public-domain/insignia template notices. Downloaded
`thumburl` bytes are committed unchanged; no local conversion, resize or colour adjustment was
performed. No mandatory SVG rendering dependency was added.

To re-acquire a file, download its `derivative_url` to a temporary file and compare SHA-256 with
this register before replacing anything. Live URLs may change as source files evolve; the committed
PNG byte checksum is authoritative for this review. Original-file SHA1 identifies source artwork
as reported by Wikimedia; direct original SVG acquisition was rate-limited (HTTP 429), so it is
not represented as an independently recalculated checksum. Review the linked frozen source page
and original upload history if source identity must be re-established later.

1920-pixel-wide files provide adequate source resolution for 1080p bounds while preserving each
flag's proportions (including 2:1 Canada/Ireland). The source API's integer SVG dimensions can be
rounded; PNG rasterisation rounds height independently. Tests allow only a small ratio tolerance
relative to those recorded source dimensions; they do not force a common aspect ratio. The human
reviewer must compare normative proportions/designs from the official evidence as well.

## Rights questions requiring explicit human disposition

1. Canada: the particular file page includes a business-use notice directing requests to
   Canadian Heritage. Check whether this educational monetised-video use requires permission
   and record the outcome. The [Canadian Heritage description](https://www.canada.ca/en/canadian-heritage/services/flag-canada-description.html)
   also flags trademark protection. Do not infer clearance from copyright status.
2. Sweden: the source credit quotes restrictions on use of national insignia in commercial
   marks suggesting state endorsement. Review the use context and record the conclusion.
3. India, Mexico, Brazil, South Africa and the remaining countries: national-symbol laws,
   display conventions and insignia protections may constrain depiction independently of copyright.
   Review source notices and relevant official guidance, including respectful orientation/display.
4. Portugal: excluded until artwork colour concerns are resolved. Its copyright designation alone
   does not make the asset visually suitable.

No source declares a CC-BY/CC-BY-SA obligation for these selected files. If a replacement does,
record the exact licence and attribution and obtain editorial review of distribution obligations.
A string accepted by the publication validator is not proof of legal usability.
